# Kosmo SPA — сайт спа-салона

Многостраничный статический сайт для спа-салона Kosmo SPA (Минск, просп. Дзержинского, 115, цокольный этаж, помещение 420). Чистые HTML, CSS и JavaScript, без сборки.

## Особенности
- Спокойный спа-стиль: оливковый, камень и золото, шрифт Cormorant Garamond.
- **Переключатель светлой («камень») и тёмной («вечер») темы**, выбор запоминается.
- **Подбор программы**: два вопроса, и сайт предлагает ритуал с ценой и кнопкой записи.
- **Дыхательная пауза**: анимированный круг «вдох, пауза, выдох».
- Прайс всех программ, FAQ, анимированные счётчики и полосы отзывов, плавное появление блоков (отключается при «уменьшить движение»).
- На телефоне внизу панель «Позвонить» и Telegram.

## Страницы
`index.html`, `programs.html`, `quiz.html`, `faq.html`, `contacts.html`.

## Запуск
`python3 -m http.server 8000` и открыть http://localhost:8000

## GitHub Pages
Загрузите содержимое папки в корень репозитория, затем Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Что править
- **Цены и программы** — `programs.html` и данные в `main.js` (объект `P`, блок «подбор программы»). Меняйте в обоих местах.
- **Телефон и Telegram** — футер каждой страницы, `contacts.html`, `main.js`.
- **Режим работы** — взят с таблички на двери (9:00–21:00 ежедневно), проверьте актуальность.
- **Цвета обеих тем** — переменные в начале `style.css`.
- Шрифты: Cormorant Garamond и Manrope (Google Fonts).

Данные взяты с карточки на Яндекс Картах (раздел «Товары и услуги» обновлён представителем салона).
